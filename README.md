# TacticLens 🎯

> AI-powered tactical match explainer — IBM June Innovation Challenge 2026

## Problem
The FIFA World Cup is watched by billions, yet tactical analysis remains
inaccessible to the average fan. Formations shift, momentum swings, and
VAR decisions confuse millions — all without clear explanation.

## Solution
TacticLens transforms match reports into structured, AI-generated tactical
breakdowns using IBM Granite. Any fan can understand the story of the game.

## Technical Approach
- **IBM Granite** — core LLM for tactical analysis and plain-language output
- **Docling** — parses uploaded PDF match reports
- **Langflow** — orchestrates the AI pipeline
- **FastAPI** — Python backend API
- **React** — frontend user interface

## Why It Matters
TacticLens makes football tactics understandable for every fan at the
2026 World Cup — delivering human-centered, explainable AI at global scale.
